A real 60-document knowledge base (63 indexed rows across six
category tabs), audited with 0.9.1.

Counts and section headings only. The base is a company's internal
documentation; nothing from inside the documents is reproduced here.

Three runs, in this order:

  A. 0.9.0's checker, on the base as it stood          -> 252 problem(s) found.
  B. 0.9.1's checker, on the SAME untouched base       -> 238 problem(s) found.
  C. 0.9.1's checker, after remediating the base       -> 21 problem(s) found.

A minus B is this release's false positives: 14 findings that were
never defects. Measured against an identical base state, from a copy
taken before any document was edited -- not inferred.

B minus C is remediation: real defects fixed in the documents and the
index, not checker changes.
